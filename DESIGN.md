# KAMENOTES — перебудова публічних сторінок

## Межі змін

Перебудовано головну, виробництво, художнє оформлення, монтаж, бруківку,
наші роботи та відгуки (останні два розділи — на одній сторінці).
Каталог і контакти, їхні HTML, спільні стилі та JavaScript збережено.
Дані товарів, ціни та тексти відгуків залишено без редагування.

## Архітектура

- `build-site.js` генерує статичний сайт і обслуговує перебудову з адмінки.
- `editorial-pages.js` містить шість нових шаблонів.
- `site/css/editorial.css` підключається лише на цих сторінках.
- `site/js/editorial.js` керує мобільним меню та приховує нижню панель зв’язку,
  коли в полі зору основний блок зв’язку. Каталог і контакти його не завантажують.
- `site/data/products.json` та `reviews.json` — наявні дані адмінки.

## Дизайн та структура

UI/UX skill використано для вибору мінімальної сітки, контрастної типографіки,
доступної навігації й адаптивних відступів. Палітру збережено нейтральною;
фіолетовий використано для впізнаваних дій Viber.

Головна: короткий вступ і реальний цех → типи пам’ятників та приклади цін →
три виконані роботи → майстерня та послуги → замовлення → зв’язок.
Знято дублювання каталогу, переваг, матеріалів, відгуків та контактів у багатьох блоках.
Ціни на головній беруться з того самого джерела, що й каталог; посилання
відкривають конкретну модель з її комплектацією.

Послуги: прямі назви, приклади реальних робіт, практична інформація.
Відгуки: всі опубліковані записи без скорочення та без вигаданих цитат.
Мобільна навігація: доступний елемент details, закриття Escape, панель зв’язку.
По одному основному Viber CTA в змісті кожної сторінки. Посилання відкриває
чат з наявним номером; запуск стороннього застосунку автоматично не тестувався.

## Матеріали старого сайту

Перевірено структуру та факти за першоджерелами:

- [Головна](https://kamenotes.com/ua/) — напрямки роботи, 1995 рік, матеріали та замовлення.
- [Майстерня](https://kamenotes.com/ua/about.html) — розпил, полірування, різьблення, доставка.
- [Встановлення](https://kamenotes.com/ua/mounting.html) — послідовність та фотографії монтажу.
- [Портрети](https://kamenotes.com/ua/services/portret.html) — ручне гравіювання.
- [Ретуш](https://kamenotes.com/ua/services/retush.html) — окрема партнерська послуга.
- [Бруківка](https://kamenotes.com/ua/services/329-bruschatka.html) — види, матеріали та оптові замовлення.

Використано наявні оригінальні зображення в `site/img/kamenotes/` і фото цеху.
Додаткові фото монтажу перенесені без редагування з
`https://kamenotes.com/pictures/montazh/montazh-pamyatnika-{номер}.jpg`
до `site/img/mounting/`: 01, 03, 05, 09, 12, 16, 35.
Водяні знаки залишено. У частини архівних фото невелика роздільність;
їх не видаємо за фотографії високої якості.
Старі рекламні гарантії, знижки та ціни послуг не перенесено як нові обіцянки.

## Збірка та перевірки

```sh
node build-site.js
node server.js
node verify-site.js
node verify-redesign.cjs
```

Для браузерних перевірок потрібні Playwright та Microsoft Edge.
Перша перевірка включає каталог, ціни, фільтри, перегляд фото, старі маршрути
та операції адмінки з видаленням тимчасових тестових записів.
Друга перевіряє незмінність захищених сторінок і їхніх залежностей, локальні
ресурси, вісім сторінок на 375/768/1024/1440 px, мобільне меню, повернення фокуса,
всі відгуки й відсутність повторних Viber CTA в основному змісті.
Візуальні знімки зберігаються в ігнорованій папці `qa/`.

Зміни локальні; публікація на production не виконувалася.
