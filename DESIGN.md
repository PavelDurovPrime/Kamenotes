# KAMENOTES — графітова палітра

## Структура проєкту

Статичні HTML/CSS/JS без фреймворку. `build-site.js` генерує сторінки,
`site/css/style.css` та `site/js/main.js`. `design-system.css` містить спільну
типографіку, компоненти й адаптивність; `home.css`, `production.css` і
`reviews.css` — стилі окремих сторінок. `server.js` обслуговує локальний сайт
і наявну адмінку. Каталог і відгуки зберігаються в `site/data/`.

Під час аудиту знайдено повторні визначення палітри в базових стилях,
пізній коричневий набір токенів у `design-system.css`, окремі теплі кольори
у відгуках і виробництві, синюваті тіні та темний повноекранний hero головної.

## Єдине джерело кольорів

`site/css/theme.css` підключається перед компонентними стилями.
Усі кольори публічних CSS, включно з hover, обводками й тінями, використовують
його змінні. Повторні визначення кольорових токенів видалені.

| Роль | Токен | Колір |
| --- | --- | --- |
| Основний фон | `--bg` | `#F5F5F3` |
| Другорядні поверхні | `--surface` | `#EEEEEC` |
| Виразніша світла поверхня | `--surface-strong` | `#E5E5E2` |
| Білий | `--white` | `#FFFFFF` |
| Основний текст | `--text` | `#252525` |
| Кнопки й темні акценти | `--graphite` | `#111111` |
| Hover | `--graphite-2` | `#353535` |
| Другорядний текст | `--muted` | `#666663` |
| Лінії | `--line` | `#D9D9D5` |

Viber зберігає впізнаваний насичений фіолетовий колір сервісу.
Фотографії та логотип збережені в оригінальних кольорах.

## Межі змін

- Каталог і контакти: розмітка основного вмісту, порядок, геометрія,
  картки, пошук, фільтри та логіка залишені без змін.
- Головна: світлий hero з фото реального цеху; категорії; моделі з цінами;
  готові роботи; виробництво й матеріали; етапи замовлення; послуги;
  наявні відгуки; консультація та контакти.
- Інші сторінки: спільна нейтральна палітра зі збереженням композиції.
- Невелике виправлення спільного футера: колонки вкладаються у ширину
  планшета між 901 і 1199 px.

Картки головної використовують `renderProductCard` і ті самі дані, що каталог.
Під час оновлення товарів або відгуків локальна адмінка перебудовує головну.
Ціни, комплектації, фото та відгуки не вигадувалися й не змінювалися.
Вибрані моделі не позначені як бестселери: статистики продажів у даних немає.

Публічний [старий сайт](https://kamenotes.com/ua/) використано для звірки
напряму й структури. Доступ до старої адмінки для цієї зміни дизайну не потрібен;
актуальність цін у ній окремо не перевірялася.

## Збірка й перевірка

```sh
node build-site.js
node server.js
# В іншому терміналі, з доступним пакетом playwright і Microsoft Edge:
node verify-site.js
```

Візуальна перевірка: 375, 768, 1024, 1440 px.
Порівняння координат і розмірів кожного DOM-елемента всередині `main`
каталогу та контактів із початковим станом: 0 змін на всіх чотирьох ширинах.
Знімки й результати локальних порівнянь — в ігнорованій Git папці `qa/`.

`verify-site.js` пройшов: локальні файли й зображення, 8 сторінок на 4 ширинах
без горизонтального переповнення, ціни головної, переходи категорій, пошук,
фільтри, перегляд фото й Escape, старі маршрути, операції створення/оновлення/
видалення товарів і відгуків із відновленням даних, відсутність помилок JavaScript.
Застарілі очікування тесту щодо заголовка бруківки й розмітки відгуків
узгоджені з наявними сторінками. HTML-вміст усіх 7 сторінок, крім головної,
порівняно з Git HEAD: без змін, оновлено лише підключення стилів у `head`.

Google Maps iframe не завантажився в тестовому браузері. Його адреса та
посилання на маршрут залишені без змін; роботу зовнішньої карти тест не підтверджує.
